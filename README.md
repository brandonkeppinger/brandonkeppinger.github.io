# Brandon Keppinger — Personal Website

A minimal GitHub Pages website using plain HTML and CSS.

## Structure

- `index.html` — homepage
- `about.html` — bio/about page
- `projects.html` — projects page
- `blog/index.html` — blog landing page
- `blog/first-post.html` — example blog post
- `assets/styles.css` — site styling
- `404.html` — simple not-found page

## Edit before publishing

Search the files for these placeholders:

- `YOUR_EMAIL_HERE`
- `YOUR-LINKEDIN-HERE`

## Deploy

In your `brandonkeppinger.github.io` repo folder:

```bash
git add .
git commit -m "Launch personal website"
git push origin main
```

Your site should appear at `https://brandonkeppinger.github.io` once GitHub Pages finishes publishing.
